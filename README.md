# FlappyBird

​	此项目为cocos学习的第四个项目，是用 **Cocos Creator 3.8.2**版本开发的2D项目，模仿经典游戏FlappyBird。

![image-20260513215414810](https://raw.githubusercontent.com/1578760644/FlappyBird/refs/heads/master/image-20260513215414810.png)

## 主要功能：

- 点击屏幕进行跳跃
- 通过管道得分
- 碰撞管道或地面游戏失败
- 实时记录当前分数
- 本地存储最高分



## 设计思路：

- 需要3个UI界面，分别是显示游戏开始状态、游玩状态、结束状态
  - 通过GameReadyUI和GameOverUI脚本来管理游戏的开始和结束
- 背景和管道的移动
  - 让背景和管道的移动实现小鸟飞行移动的错觉
  - 用两张相同的背景，通过图片位置的循环移动来实现背景滚动
- 管道随机生成
  - 设定管道生成的时间
  - 通过Y轴来改变管道随机生成的位置
  - 管道超出屏幕进行销毁
- 通过触摸事件来控制小鸟移动
  - 在Bird里写入触摸事件控制小鸟的移动
  - 实现小鸟飞行效果，小鸟是在原地进行上下跳跃
- 飞行动画
  - 添加小鸟飞行动画
  - 根据不同得分，飞行动画不同（只是预留了动画，目前还没有实现功能）
- 碰撞事件
  - 给管道和地面添加碰撞器组件
  - 碰到管道和地面会导致游戏失败
  - 管道中间添加触发器
- 用GameManager来统一集中管理游戏逻辑
  - 通过单例模式在外部调用
  - 用三个transitionXX状态进行游戏状态的切换
  - 通过回调函数避免与Bird脚本的循环引用
- 得分事件
  - 小鸟通过管道中的触发器时获得一分
  - 当局分数大于最高分数时，显示new标签并把分数存入最高分
- 用GameData来进行数据的存储与管理
  - 通过单例模式在外部调用
  - 分数存储在本地
- 分数显示
  - 游戏中在上方显示当前分数
  - 游戏结束后显示当局分数和最高分
  - 根据当局分数判断获得奖牌类型
- 用单例模式来管理音频
  - 使用官方文档里的示例



根据设计思路可以得知需要的脚本（TypeScript）如下：

- 控制游戏开始UI和结束UI
  - GameReadyUI
  - GameOverUI
- 单例模式
  - GameManager
  - GameData
  - AudioMgr
- 逻辑控制
  - Bird
  - MoveBg
  - Pipe
  - PipeSpawner

*因为项目简单，并没有进行严格的通过`GameManager` 统一处理全局点击，后续还可以进行优化*
